TESTES HTTPie

Inicie a API conforme o README:

python main.py

Instale o cliente HTTPie:

python -m pip install httpie

API Key de demonstração: exemplo1234567y

Envie um comando por vez:

http GET http://127.0.0.1:5000/ X-API-Key:exemplo1234567y

http -a admin:1234 GET http://127.0.0.1:5000/alunos X-API-Key:exemplo1234567y

http -a admin:1234 GET http://127.0.0.1:5000/alunos/95633 X-API-Key:exemplo1234567y

http -a admin:1234 GET 'http://127.0.0.1:5000/alunos?curso=Engenharia%20de%20Computa%C3%A7%C3%A3o' X-API-Key:exemplo1234567y

http -a admin:1234 POST http://127.0.0.1:5000/alunos nusp:=88888888 nome=Bruno email=bruno@usp.br curso=Computacao ano_ingresso:=2026 X-API-Key:exemplo1234567y

http -a admin:1234 PUT http://127.0.0.1:5000/alunos/88888888 nome='Bruno Silva' email=bruno@usp.br curso=Computacao ano_ingresso:=2026 X-API-Key:exemplo1234567y

http -a admin:1234 DELETE http://127.0.0.1:5000/alunos/88888888 X-API-Key:exemplo1234567y

http -a admin:1234 GET http://127.0.0.1:5000/disciplinas X-API-Key:exemplo1234567y

http -a admin:1234 GET http://127.0.0.1:5000/matriculas X-API-Key:exemplo1234567y


RESPOSTAS DE ERRO PARA EXPERIMENTAR

http -a admin:1234 GET http://127.0.0.1:5000/alunos/999999 X-API-Key:exemplo1234567y

http -a admin:1234 POST http://127.0.0.1:5000/alunos nusp:=95633 nome=Outra email=outra@usp.br curso=Computacao ano_ingresso:=2026 X-API-Key:exemplo1234567y

http -a admin:1234 DELETE http://127.0.0.1:5000/alunos/95633 X-API-Key:exemplo1234567y

Em HTTPie, campo=valor envia texto; campo:=2026 envia número JSON.
O HTTPie é um cliente opcional; não é dependência do servidor.


AUTENTICAÇÃO E AUTORIZAÇÃO

Os usuários são criados pelo popular_banco.py.

Credenciais de demonstração:
- API Key: exemplo1234567y
- Administrador: login admin, senha 1234
- Alunos: login e senha iguais ao NUSP

As credenciais são exclusivamente para fins didáticos.


# Sem API Key: 401

http -a admin:1234 GET http://127.0.0.1:5000/alunos


# API Key incorreta: 401

http -a admin:1234 GET http://127.0.0.1:5000/alunos X-API-Key:chave-incorreta


# API Key válida, sem credenciais do usuário: 401

http GET http://127.0.0.1:5000/alunos X-API-Key:exemplo1234567y


# API Key válida, senha incorreta: 401

http -a admin:senha-incorreta GET http://127.0.0.1:5000/alunos X-API-Key:exemplo1234567y


# Aluno: 200 (próprios dados)

http -a 95633:95633 GET http://127.0.0.1:5000/alunos/95633 X-API-Key:exemplo1234567y

http -a 95633:95633 GET http://127.0.0.1:5000/matriculas X-API-Key:exemplo1234567y

http -a 95633:95633 GET http://127.0.0.1:5000/disciplinas X-API-Key:exemplo1234567y


# Aluno: 403 (outro aluno ou rota administrativa)

http -a 95633:95633 GET http://127.0.0.1:5000/alunos/95634 X-API-Key:exemplo1234567y

http -a 95633:95633 GET http://127.0.0.1:5000/alunos X-API-Key:exemplo1234567y

http -a 95633:95633 DELETE http://127.0.0.1:5000/alunos/95633 X-API-Key:exemplo1234567y


# Aluno: matrícula própria (200); matrícula alheia (404).
# IDs 1 e 5 correspondem, respectivamente, ao primeiro aluno
# e a outro aluno na base fictícia gerada pelo script original.

http -a 95633:95633 GET http://127.0.0.1:5000/matriculas/1 X-API-Key:exemplo1234567y

http -a 95633:95633 GET http://127.0.0.1:5000/matriculas/5 X-API-Key:exemplo1234567y


# Administrador: 200 (todos os dados)

http -a admin:1234 GET http://127.0.0.1:5000/alunos X-API-Key:exemplo1234567y

http -a admin:1234 GET http://127.0.0.1:5000/matriculas X-API-Key:exemplo1234567y
